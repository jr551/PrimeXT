# Third-party components for the optional browser build

The files added for that build were generated with AI (Cursor).

## Xash3D FWGS

The page uses the npm package `xash3d-fwgs@1.2.2` (MIT) as the engine. PrimeXT is still only the client and server libraries.

## webXash

Browser loading ideas were adapted from [webXash](https://github.com/x8BitRain/webXash) (MIT). No webXash source is copied here.

The test fetches the free Half-Life: Uplink demo zip that webXash redistributes. That zip is not committed. Retail Half-Life assets are not part of this tree.

## Emscripten

https://github.com/emscripten-core/emsdk — used only when building the browser modules.
